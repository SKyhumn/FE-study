# 6.Hosting

## 호스팅이란?

웹사이트나 앱이 인터넷에서 누구나 접속할 수 있도록 **서버 공간과 환경을 빌려주는 서비스**를 말한다.

## Firebase Hosting

**Firebase Hosting**은 구글에서 제공하는 서비스로, **웹사이트를 인터넷에 배포(호스팅)할 수 있는 플랫폼**이다.

## 장점

- 서버 설정 필요 없음 → 배포가 간단
- SSL 자동 적용 → HTTPS 지원
- SPA(Single Page App) 지원 → React, Angular 같은 앱 배포 가능
- 전 세계 CDN → 빠른 로딩

## 호스팅 하는 법

### 1.Firebase CLI 설치

```bash
npm install -g firebase-tools
```

### 2.로그인

```bash
firebase login
```

그 뒤에 여러 질문들이 나오는데 Y로 터미널에 적은 뒤 CLI 로그인 성공 여부를 확인한다.

![image.png](attachment:cbc962ff-1624-45e4-8134-8bb51c9b6cc3:image.png)

### 3.Hosting 초기화

```bash
firebase init hosting
```

### 선택해야 할 옵션 (중요)

### ① **Hosting: Configure files for Firebase Hosting…** 선택

(스페이스바 → 엔터)

### ② **Use an existing project** 선택

→ 이미 Firebase 콘솔에 만든 프로젝트 선택

### ③ **Public directory:**

React 프로젝트는 **build** 입력해야 함

```
build
```

### ④ **Configure as a single-page app?**

React Router 사용 → **Yes**

(모든 경로를 index.html로 돌려줌)

### ⑤ GitHub 자동 배포?

보통 **No**

(원하면 나중에 설정 가능)

### 4.React 빌드 생성

```bash
npm run build
```

→ 프로젝트 안에 `/build` 폴더가 생김.

### 5.Firebase Hosting

```bash
firebase deploy
```

성공하면

```bash
Hosting URL: https://<프로젝트명>.web.app
```

이런 식으로 URL이 터미널에 표시된
